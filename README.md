# Projet de CV « Xavier le Magnifique »

## 1. Présentation

Pourquoi « Xavier le Magnifique » ? Non par narcissisme, mais parce que ce projet de CV en ligne a été conçu dans le cadre d'une piscine web d'Epitech. La créativité et le rendu visuel étant attendus pour ce travail, l'idée nous est venue de nous inspirer de l'esthétique du film *Gatsby le Magnifique* (2013) pour reproduire une atmosphère élégante.

## 2. Lien vers le résultat

https://xnew2tw.github.io/

## 3. Fonctionnalités

Ce CV contient les sections classiques que l'on peut attendre de cet exercice de présentation de soi sous forme de document :

- les compétences techniques ;
- les compétences professionnelles ;
- les langues étrangères maîtrisées ;
- les expériences professionnelles ;
- les projets ;
- les formations suivies ;
- les contacts.

À cette structure conventionnelle s'ajoute ici un formulaire à remplir pour contacter l'auteur du site. Cette présence est bienvenue, puisque ce projet vise à progresser en développement web.

## 4. Technologies utilisées

Ce CV a été conçu exclusivement en langage HTML pour son organisation et sa structure, puis habillé de styles obtenus grâce au langage CSS. Chacun de ces langages a été utilisé dans sa forme la plus pure : sans framework, sans bibliothèque et sans JavaScript.

## 5. Structure du projet

Le dossier parent contient trois éléments indispensables à ce projet :

- le fichier index.html, qui est la fondation de cette page web ;
- le fichier style.css, contenu dans le dossier css, sans lequel cette page serait bien moins belle ;
- le dossier fonts, qui nous a été indispensable pour utiliser les polices Gatsby Inline (pour le nom) et Gatsby FLF (pour les titres).

À ce propos, il est à noter que le choix des polices Gatsby visait à retranscrire une atmosphère proche de celle du film de 2013. Si, avec Gatsby Inline, nous avons tenté de nous approcher du style des affiches du film, avec l'effet métallique de son titre, Gatsby FLF nous a permis d'apporter une touche Art déco, indissociable de l'époque à laquelle se déroule l'action du roman et de son adaptation.

## 6. Utilisation

Pour consulter ce CV, ouvrez le lien public https://xnew2tw.github.io/, ou clonez le dépôt disponible sur GitHub, puis ouvrez le fichier index.html dans un navigateur.

## 7. Limites connues

Certains éléments ne fonctionnent pas aussi bien que nous le souhaitions. Le plus évident est sans doute la partie du formulaire consacrée à l'envoi d'un courriel via le schéma d'adresse `mailto:`. Le langage HTML nous a limité à une option : transformer le formulaire rempli en un courriel qui serait envoyé à notre adresse électronique. Mais il s'agit d'une impasse pour les utilisateurs qui ne disposent pas d'un logiciel de messagerie configuré. Nous avons eu l'honneur de le constater lors d'un test.
